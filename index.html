5.0Installation

  1. Download the package from github.com/HelixDB/helix-mono.
  2. For desktop use, open each file in fonts/ttf and select Install.
  3. For the web, copy fonts/woff2 into your project and declare it with @font-face.
  4. Set your editor or terminal font to Helix Mono.
@font-face {
  font-family: "Helix Mono";
  src: url(HelixMono-Regular.woff2) format("woff2");
  font-weight: 400;
}
